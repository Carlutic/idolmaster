# 偶像大师 模型库

本仓库是 [Carlutic/model-viewer](https://github.com/Carlutic/model-viewer) 的「Idolmaster」分类模型库。

包含学园偶像大师（花海咲季、花海佑芽、藤田琴音、篠泽广）与 BanG Dream! MyGO!!!!!/Ave Mujica 角色（要乐奈、千早爱音、若叶睦、长崎爽世、三角初华、丰川祥子，按用户要求统一归入偶像大师分类）。

模型文件原始分辨率；其中 MyGO/Ave Mujica 的同人版由作者的 .blend 使用 mmd_tools 转换导出为 PMX。
